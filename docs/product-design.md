# 月迹产品与交互设计

## 1. 产品定位

月迹（hercula）是一个只在本机工作的月经记录工具。它不要求注册，不上传经期数据，不接入广告或行为分析。用户打开应用后可以快速确认今天是否来月经，并从同一界面向下查看历史与导入导出。

### 首版目标

- 3 秒内完成“今天来月经”的记录。
- 能看见每次经期的开始日期、持续天数和当前是否仍在记录。
- 用明确标注“估算”的方式显示下一次经期，不把算法结果包装成医疗结论。
- 可以从文本或 JSON 恢复数据，也可以导出可读、可迁移的 JSON。

### 不在首版范围

- 症状、情绪、经量、用药、排卵、备孕或疾病诊断。
- 云端同步、账号体系、推送提醒、广告、统计 SDK。
- 与系统健康数据或其他设备自动同步。
- 依赖联网大模型的解析。

## 2. 页面与手势

应用只有一个 UIAbility 和一个入口页面，入口页面内部由两个满屏展示页组成：

### 页面一：今日日历

- 顶部显示“月迹”和当前月份。
- 主体为自绘的 7 列月历网格，当前日期有清晰的焦点状态。
- 点击当前日期：切换今天的经期标记。首次点击新增今天，重复点击撤销今天；撤销前需要轻量确认，避免误触丢数据。
- 已标记日期使用低饱和粉红底色；当前正在记录的连续区间使用更深的红粉色；今天使用浅蓝色细节点缀，保证与经期色有区分。
- 月历只允许浏览和查看历史月份；首版只允许直接修改今天，历史修正通过导入或后续编辑能力完成。这样保持“一个动作完成记录”的产品主线。
- 页面底部用小提示说明：再次点击可撤销，历史记录会在下方页面查看。

### 页面二：历史统计

- 通过一次向上/向下手势切换到历史页，页面切换按整页吸附，不采用自由滚动。
- 上半部为无边框的横向水平柱状图：每一行是一次经期，日期作为左侧行标签，柱条长度表示持续时长。最后一条未结束记录以“截至今天”计算，并带有“进行中”标记。
- 不绘制持续天数坐标轴、网格线、刻度或外框；每条柱的持续天数显示在柱条末端，例如“5天”。空数据状态显示引导，不显示伪造柱子。
- 图表下方同步提供文本摘要，以便无障碍朗读和在窄屏上阅读：例如“2026-08-01，持续 5 天”。
- 底部固定两个操作：导入、导出。导入完成后先展示解析预览与冲突数量，用户确认后才写入本地数据。

确认版图表结构：

```text
日期标签        水平柱条                         末端时长
2026-04-02      █████                            5天
2026-05-01      ████                             4天
2026-06-03      ██████                           6天
2026-08-01      █████                            进行中
```

柱条不带边框，页面不显示持续天数坐标轴；日期是记录行的唯一轴向信息，时长由柱条长度和末端文字共同表达。

### 导入流程

1. 点击“导入”。
2. 选择“从文件导入”或“粘贴文本”。文件通过系统 DocumentViewPicker 取得临时 URI 授权。
3. 先解析为候选日期，不直接覆盖现有数据。
4. 显示识别到的日期、无法识别的片段、重复日期和待新增日期。
5. 用户确认后合并；已有日期保持幂等，不创建重复记录。

首版“任何形式的文本”定义为：应用尽力识别常见日期表达式，但不承诺识别所有自然语言。无法确认的内容必须进入待确认列表，而不是静默猜测。

### 导出流程

1. 点击“导出”。
2. 通过系统保存文件选择器选择位置和文件名，默认建议 `hercula-export-YYYY-MM-DD.json`。
3. 写出版本化 JSON；成功后提示保存位置，失败时保留原数据并显示可重试错误。

## 3. 视觉方向

### 色彩

| 用途 | 建议色 | 说明 |
| --- | --- | --- |
| 页面背景 | `#F7F1F2` | 低饱和暖白粉 |
| 主卡片 | `#F1DDE1` | 大面积柔和粉色 |
| 经期标记 | `#C98291` | 与背景有足够对比 |
| 当前日期强调 | `#A95E70` | 用于焦点和关键文本 |
| 对比点缀 | `#B8D1D5` | 浅蓝灰，只用于今天/辅助状态 |
| 正文 | `#594B50` | 避免纯黑的莫兰迪深色 |

颜色只是初始 token；开发时必须在真实设备上检查对比度、深色模式和系统字体放大效果。

### 形状、层次与动效

- 采用大圆角卡片，建议圆角 token 为 24vp，按钮不低于 16vp。
- 日历外层用多层半透明背景和渐变边缘制造“柔和包裹感”，不使用高成本实时模糊作为核心效果。
- 页面切换使用自然的纵向滑动和短时缓动；不叠加会遮挡日期信息的装饰动画。
- 触控目标至少满足系统可用性要求；颜色不是唯一状态表达，必须配合日期数字、点、文本或图例。

## 4. 空状态与错误状态

- 无记录：显示“先记录今天，月迹会慢慢形成”，图表区域不画 0 高度柱。
- 只有 1 次经期：显示历史时长，但不显示下一次预测，并说明“至少需要更多完整记录”。
- 导入部分失败：显示成功日期数、重复数、失败片段数，允许只导入可确认的部分。
- 导出失败：不删除或回滚已有记录，只显示失败原因和重试入口。
- 预测不确定：显示日期区间和“仅供记录参考”，不使用“准确”“安全期”等词。
