# 月迹 UI 动效探索

本文只记录可在 ArkUI 原生能力内验证的动效方向。动效必须服务于“记录、切换、确认”三个动作，不用动画掩盖状态变化，也不把高成本实时模糊作为必要依赖。

## 当前已具备

- 年/月浮动窗：向下浮现并带透明度过渡。
- 月份切换：拖动期间显示目标月份的部分内容，松手后连续缓动完成切换。
- 页面切换：外层纵向分页保持整页切换语义。

## 候选动效

### P0：日期记录反馈

点击日期后只对被点击日期做一次短促的缩放/透明度回弹，颜色变化立即生效。取消记录使用相同的反向反馈，避免新增和取消产生不同的认知路径。

验收：连续点击不同日期不会积累动画；未来日期无反馈；动画结束后日期颜色和持久化状态一致。

### P1：历史柱体进入

历史页第一次出现时，柱体从 0 到目标宽度缓动，日期标签和末端时长保持稳定位置。列表重新排序时不使用逐条跳动，避免用户误以为记录被修改。

验收：0、1、很多条记录都不溢出；柱体长度最终与静态比例一致；系统减少动画设置时仍可读。

### P1：年月浮动窗选择态

浮动窗保持现有向下出现动画；点击年份或月份后，仅高亮按钮和月历内容更新，不重复播放整块浮窗动画。点击当前选项可关闭浮窗。

验收：打开、选择、再次打开连续操作不闪烁；浮窗上下圆角一致；按钮间距和边缘留白在不同窗口宽度下保持比例。

### P2：跨年提示

年份标识已经穿插在相邻日期行之间，不占用列表高度。出现或消失只使用淡入淡出，不添加新的列表行移动动画。

验收：跨年边界只出现一次；首条记录不显示当前年份；列表排序变化不会产生重复年份标识。

## 多设备动效约束

- Pura X 折叠态优先保留核心日期操作，不引入依赖横向空间的复杂动画。
- 宽折叠展开、平板和直板屏可以增加柱体进入动画，但动画时长、触控目标和文本可读性不能随像素线性放大。
- 系统“减少动态效果”或低性能设备场景下，所有动画必须可降级为即时状态切换。
- 任何动效新增前，先在 980×980、1320×2120、2210×2416、1080×2444 和 1320×2856 规格上检查裁剪、重叠和手势冲突。

## 暂不采用

- 持续实时毛玻璃作为核心背景效果：设备差异和性能成本尚未验证。
- 柱体弹簧式反复回弹：会削弱日期和时长信息的稳定性。
- 页面整体缩放或旋转：不符合当前克制、低饱和的视觉方向。
